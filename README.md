# Spam Email Detector

## Description  
The Spam Email Detector is a simple machine learning project that classifies messages as **Spam** or **Not Spam**. It uses Natural Language Processing (NLP) techniques and the Naive Bayes algorithm. The project runs in a console environment and works offline.

---

## Features  
- Classifies messages as Spam or Not Spam  
- Fast and lightweight  
- Console-based (no GUI)  
- Uses basic machine learning concepts  

---

## Technologies Used  
- Python  
- Pandas  
- Scikit-learn  

---

##  Usage  
- Enter a message when prompted  
- The program will classify it as:  
  - Spam  
  - Not Spam  
- Type exit to stop the program  

---

## Example  

Enter your message: Win money now
- Spam Message

Enter your message: Hello friend
- Not Spam
